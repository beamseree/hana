# Working-window milestone decisions

2026-10-15, Asia/Bangkok.

## Appearance

Spec #88 describes light/dark-aware working windows, while the design system explicitly keeps working windows light until dark mode is decided. Asked which rule this milestone should use, Beam selected **“Keep the current light appearance (Recommended)”** in this implementation chat.

Main and note windows therefore keep the current light appearance for #88. This is a human scope clarification, not an automated or visual acceptance result. Dark-mode design remains later work; the bar's appearance and deferred visual/animation work are unchanged.
